# Network Devices

## Network

A computer network is a digital telecommunication network that allows nodes to share resources.

## Network Nodes

- Router
- Switch
- Firewall
- Server
- Client

### Client and Server

A client is a device that accesses a service made available by a server.

A server is a device that provides services to a client.

---

## Switches

Switches are used to forward traffic within the same LAN (Local Area Network).

### Characteristics of Switches

1. Have many ports for end hosts to connect to.
2. Provide connectivity to hosts within the same LAN.
3. Do not provide connectivity between LANs / over the internet.

---

## Routers

Routers provide connectivity between LANs / over the internet.

### Characteristics of Routers

1. Routers are used to send data over the internet.
2. They provide connectivity between LANs.
3. Have fewer interfaces than switches.

---

## Firewalls

A firewall is a special network security device that controls network traffic entering and exiting your network.

### Characteristics of Firewalls

1. Monitor and control network traffic based on configured rules.
2. Can be placed inside the network or outside the network.
3. Are known as **Next-Generation Firewalls (NGFWs)** when they include more modern and advanced filtering capabilities.

### Host-Based Firewalls

Host-based firewalls are software applications that filter traffic entering and leaving a host machine, i.e. a PC.

---

## Quick Summary

| Device | Main Function |
|---|---|
| Switch | Forwards traffic within the same LAN |
| Router | Connects different LANs and networks / provides internet connectivity |
| Firewall | Controls and filters network traffic based on security rules |
| Server | Provides services to clients |
| Client | Accesses services provided by servers |
